# Colour Codex

A painter's reference to the Warhammer 40,000 Primarchs, Legions, Chapters and successor Chapters, made for finding new colour schemes.

- Browse by Legion, or filter by armour colour, allegiance or search.
- Each entry has a short bio, a heraldic pauldron preview, copyable hex swatches, and links to Lexicanum, the Fandom wiki and an image search for real painted models.
- ★ Shortlist schemes you like (saved in your browser).

Lore is summarised from [Lexicanum](https://wh40k.lexicanum.com) and the [Warhammer 40k Fandom wiki](https://warhammer40k.fandom.com). Swatches are approximations of described liveries, not official paint matches. Unofficial fan reference, not affiliated with Games Workshop.

Plain HTML/CSS/JS with no build step. All data lives in `data.js`. Add a chapter by appending to `CHAPTERS`.
